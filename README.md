# DayHub Android 0.1 — исходный проект

**Это исходники, не готовый APK.** Сборка не проверялась в Android SDK в текущей среде. Требуется GitHub Actions.

## Что работает в прототипе
- Экран из 6 разделов
- Open-Meteo по последней доступной геопозиции; нужна разрешённая геолокация и предварительное определение координат устройством
- Чтение ближайших 48 часов из Android Calendar Provider
- Ссылка на плейлист YouTube Music, сохранённая локально
- RSS-ленты: мир, Украина, Болгария, ИИ (доступность адресов может меняться)
- Gmail и Telegram: **только заглушки**, без чтения данных

## Как собрать только с телефона
1. Создать новый **приватный** репозиторий на github.com (для личных данных не использовать публичный).
2. Распаковать архив. Через мобильный браузер GitHub загрузить содержимое папки dayhub-starter в корень репозитория, сохраняя структуру каталогов и скрытую папку `.github/workflows`. Если мобильная загрузка неудобна, использовать GitHub Codespaces (при наличии бесплатной квоты) или Termux + git.
3. Открыть GitHub → Actions → Build Android APK → Run workflow (или дождаться сборки после push в main).
4. Скачать артефакт `DayHub-debug-apk`, распаковать и установить `app-debug.apk`. Android попросит разрешение на установку APK из выбранного приложения.
5. В DayHub дать только необходимые разрешения на геолокацию и календарь.

## Ограничения и безопасность
- APK debug, для личного тестирования, не для Play Store.
- Не добавляйте токены и пароли в репозиторий.
- Доступ к Gmail и Telegram ещё не реализован.
- Фоновые задания ещё не реализованы.
- Новостные RSS не являются независимой проверкой фактов или отбором по важности.
- Разрешение геолокации используется для отправки координат в Open-Meteo по HTTPS. Почта и Telegram не передаются.
- Приложение не использует OpenAI API и не генерирует ИИ-черновики.
- Бесплатные лимиты GitHub Actions зависят от тарифа и текущих условий.
